# EventManagementService

Сервис управления мероприятиями на ASP.NET Core с REST API.

## Описание

Приложение предоставляет полный функционал для управления событиями:
- Получение списка всех событий
- Создание новых событий
- Обновление существующих событий
- Удаление событий
- In-memory хранилище
- Автоматическая документация API через Swagger

## Требования

- .NET SDK 9.0 или выше
- Windows / Linux / macOS
- Git (рекомендуется)

## Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone https://github.com/alex-ria/EventManagementService.git
cd EventManagementService
```

### 2. Восстановить зависимости

```bash
cd EmsApi
dotnet restore
```

### 3. Запустить приложение

```bash
dotnet run
```

### 4. Открыть в браузере

- **Swagger UI**: http://localhost:5243/swagger/

## API методы

### GET /events
- Описание: возвращает список всех событий.
- Ответ: 200 OK с массивом объектов событий.

### GET /events/{id}
- Описание: возвращает событие по id.
- Параметры: `id` (целое число).
- Ответ: 200 OK с объектом события или 404 если не найдено.

### POST /events
- Описание: создаёт новое событие.
- Тело (JSON): `title`, `description`, `startAt`, `endAt`.
- Ответ: 201 Created с созданным объектом.

### PUT /events/{id}
- Описание: обновляет существующее событие по id.
- Параметры: `id`.
- Тело (JSON): те же поля, что и для POST.
- Ответ: 200 OK с обновлённым объектом или 404 если событие не найдено.

### DELETE /events/{id}
- Описание: удаляет событие по id.
- Параметры: `id`.
- Ответ: 200 OK при успешном удалении или 404 если событие не найдено.
